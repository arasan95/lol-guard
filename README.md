# LoL Guard

LoLのメインスレッドを専用コアに固定し、他アプリを残りのコアへ隔離するWindows常駐ツール（Rust製・単一exe）。Windowsが英語なら英語UI、日本語なら日本語UIで表示されます。

## 入手方法（ビルド不要）

1. [Releases](../../releases) から最新の `lol-guard.exe` をダウンロードする
2. 好きなフォルダに置いてダブルクリックする（インストール不要）
3. タスクトレイに常駐します（初回は設定ファイル `cores.json` を自動生成）

ソースからビルドしたい場合のみ次が必要です（通常は不要）。

## 基本的な使い方

1. LoLを起動する
2. トレイの「今すぐ最適化」を押す（または45秒ごとの自動適用を待つ）
3. メインスレッドが専用コアに固定され、他アプリは残りのコアへ移動します
4. 終わったらトレイの「元に戻す」で全CPUに戻せます

## どうなるか

- LoLメインスレッド → 専用コア（既定：最終論理CPU）に固定
- LoLの他スレッド → 別コアに固定
- 他アプリ → 残りのコアへ移動（ゲーム用コアから退去）
- LoL起動中は45秒ごとに自動で再適用（PID/TIDが変わっても追従）
- 「設定を開く」でコア割当を変更可能、「自動起動を登録」でログオン時から管理者常駐
- 追加の専用化（既定ON）：メインスレッド優先度Highest、移動した裏プロセスBelowNormal、電源プランの高パフォーマンス化、システムタイマ1ms化
- 任意：Game DVR無効化（設定ファイルの `game_dvr_off`）

## ビルド

```sh
cargo build --release --manifest-path tools/lol-guard/Cargo.toml
```

成果物：`tools/lol-guard/target/release/lol-guard.exe`（約0.5MB、ランタイム不要）

## 注意

- Vanguard・Defender等の保護プロセスやSystem系はOS制約で移動できない（失敗は無視される）
- スレッドaffinityは読取不可のため「設定成功＝適用」とみなす
- LoL再起動でPID/TIDは変わるが、常駐が検出して再適用する
- 64論理CPU超の環境は先頭64のみ対象
- 使用は自己責任で（`--restore`／トレイ「元に戻す」で全CPUに戻せる）
