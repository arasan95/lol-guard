# LoLのFPS低下を直す：CPUボトルネックの見つけ方と最適化手順

タスクマネージャーではCPUに余裕があるように見えるのに、LoLのFPSだけが落ちる。その原因の見つけ方と、自分でできる最適化の手順をまとめました。

ポイントは1つです。**LoLは約1.5〜2コア分を使いますが、その中のメインスレッド1本だけが1コア分を使い切っています。** 問題はコアの数ではなく、特定スレッドの飽和です。

## 1. 計測方法

### 1-1. コア別の使用率を見る（タスクマネージャー）

1. タスクマネージャーを開く（Ctrl + Shift + Esc）
2. 「パフォーマンス」→ CPU
3. グラフを右クリック →「グラフの変更」→「論理プロセッサ」
4. 論理プロセッサ数分のグラフが表示される

特定の1つだけが100%に張り付けば、そのコアで動くスレッドが飽和しています。ただしスレッドはコア間を移動するため、均等に見える場合もあります。その場合は次へ。

### 1-2. スレッド別の使用率を見る（Process Explorer）

Microsoft公式の無料ツールです。

1. `winget install Microsoft.Sysinternals.ProcessExplorer` でインストール
2. 一覧から `League of Legends.exe` をダブルクリック
3. **Threadsタブ**を開き、CPU列でソート

1つのスレッドだけが常に上位にいれば、それがボトルネックです。注意点として、この表示は**全コア合計に対する割合**なので、8コアPCでは1コア使い切りが約12.5%と表示されます。

### 1-3. 1コア換算で見る（パフォーマンスモニター）

Windows標準ツールです。1コア=100%で表示されるため直感的です。

1. `perfmon` を起動
2. 緑の「+」→ `Thread` → `% Processor Time` を選択
3. インスタンス一覧から `League of Legends/0` などを追加
4. 90〜100%に張り付く線がメインスレッドです

### 1-4. 計測用バッチファイルの仕組み

上記をPowerShellで自動化する場合の仕組みを解説します。読者が自分の環境用に作成できます。

**スレッド使用率の取得**：各スレッドの `TotalProcessorTime` を一定間隔で2回取得し、差分を経過時間で割ります。1コア換算のパーセントになります。

```powershell
$t1 = @{}
foreach ($th in $lol.Threads) { $t1[$th.Id] = $th.TotalProcessorTime }
Start-Sleep -Seconds 3
$lol.Refresh()
foreach ($th in $lol.Threads) {
    $pct = ($th.TotalProcessorTime - $t1[$th.Id]).TotalMilliseconds / 30
}
```

**コア別使用率の取得**：パフォーマンスカウンタ `\Processor(*)\% Processor Time` を使います。

```powershell
Get-Counter '\Processor(*)\% Processor Time' -SampleInterval 1 -MaxSamples 1
```

**TIDとカウンタインスタンスの対応付け**：パフォーマンスモニターの `League of Legends/0` のような番号とスレッドID（TID）の対応は、`ID Thread` カウンタで調べます。

```powershell
Get-Counter '\Thread(League of Legends*)\ID Thread' -MaxSamples 1
```

これらを組み合わせると、メインスレッドの使用率（1コア換算）とコア別使用率を1秒ごとに表示するモニターが作れます。

## 2. 問題の見分け方

| 症状 | 意味 |
|---|---|
| 全体60%だが特定スレッドが99%（1コア換算） | 単スレッド飽和。他アプリケーション整理＋コア隔離が有効 |
| タスクマネージャーでLoLが12%前後 | 8コアPCでは1コア飽和のサイン（100÷8=12.5） |
| vgc.exe（Vanguard）が常時10%超 | 異常値。再インストールを検討 |
| MsMpEng.exe（Defender）が常時10%超 | リアルタイムスキャンが重い。除外設定を検討 |

## 3. 最適化方法

### 3-1. 他アプリケーションを閉じる（効果：大）

プレイ中に不要な他アプリケーション（ブラウザ、エディタ、OneDrive同期など）を終了します。今回の計測では全体の約20〜30%が空きました。

### 3-2. Defenderの除外設定（効果：大）

DefenderのリアルタイムスキャンがRiotフォルダを走査している場合、除外設定で負荷を下げられます。今回の計測ではMsMpEngが約12〜19%→0%になりました。

1. Windowsセキュリティ → ウイルスと脅威の防止 → 設定の管理
2. 除外 → `C:\Riot Games` フォルダを追加

管理者権限が必要です。

### 3-3. コア隔離と優先度（効果：中）

メインスレッドが使うコアから他アプリケーションをどかします。

- LoLメインスレッド → 末尾2コアに固定
- 他アプリケーション → 残りのコアに移動
- LoLプロセスの優先度 → High

GUIで設定したい場合は **Process Lasso**（無料）で同等のルールを永続化できます。

### 3-4. 最適化バッチファイルの仕組み

コア隔離をバッチファイルで自動化する場合の仕組みを解説します。

**コア数の動的取得**：環境の論理プロセッサ数を取得し、末尾2コアをゲーム用に割り当てます。コア数を固定値で書くと他のPCで動きません。

```powershell
$LP = [Environment]::ProcessorCount
$g1 = $LP - 2; $g2 = $LP - 1
$MAIN_MASK = ([int64]1 -shl $g1) -bor ([int64]1 -shl $g2)
$BG_MASK = (([int64]1 -shl $LP) - 1) -bxor $MAIN_MASK
```

**スレッドの固定**：.NETの `ProcessThread.ProcessorAffinity` にマスク値を設定します。読み取りはできないため、設定成功をもって適用済みとみなします。なお、スレッドの affinity はプロセスの affinity の範囲内に収める必要があります（プロセス側が制限されていると範囲外への固定は失敗するため、先にプロセス側を全コア許可に戻します）。

```powershell
$lol.ProcessorAffinity = [IntPtr]$GAME_MASK   # プロセス制限を先に解除
$top.ProcessorAffinity = [IntPtr]$MAIN_MASK   # メインスレッドを固定
$lol.PriorityClass = 'High'                   # 優先度を上げる
```

**他アプリケーションの移動**：システム系・保護プロセスを除外リストに入れ、それ以外でゲーム用コアを使えるプロセスを残りのコアへ移動します。

```powershell
$Exclude = @('Idle','System','csrss','services','lsass','vgc','MsMpEng')
foreach ($p in (Get-Process)) {
    if (($p.ProcessorAffinity -band $MAIN_MASK) -ne 0) {
        $p.ProcessorAffinity = [IntPtr]$BG_MASK
    }
}
```

**自動化**：ゲーム起動ごとに affinity はリセットされるため、スタートアップに監視スクリプトを登録し、LoL起動中は定期的に上記を適用します。タスクスケジューラの登録には管理者権限が要る場合があるため、スタートアップフォルダへのショートカット配置が手軽です。

### 3-5. ゲーム内設定

上記でもメインスレッド自体の要求量は変わらないため、以下で仕事量を減らします。

- シャドウOFF・AA OFF・キャラクターインクOFF
- FPS上限の設定
- LoLクライアントの「ゲーム中に閉じる」を有効化

## 4. それでも直らない場合

- オーバークロック（倍率アンロックCPUの場合）
- HAGSの有効化（設定 → ディスプレイ → グラフィックス。小効果）
- 単スレッド性能の高いCPUへの換装（コア数ではなく単スレッド性能で選ぶ）

LoLのメインスレッドはエンジン構造上1コア分が上限のため、最終的にはCPU自体の単スレッド性能かゲーム設定の調整が必要です。

## 5. まとめ

1. コア別表示で偏りを確認する
2. スレッド別表示で犯人の1本を特定する（12%台＝1コア飽和のサイン）
3. 他アプリケーション停止 → Defender除外 → コア隔離の順に最適化する
4. 残りはゲーム設定かCPU性能で対応する
